AgentDojo 방어 기법 비교

AgentDojo 벤치마크에서 각 논문이 보고한 prompt injection 방어 기법의 Utility와 공격 성공률(ASR)을 정리했습니다.

  • Utility (no attack) 공격 없을 때 task 성공률
  • Utility (under attack) 공격 중 task 성공률
  • ASR 공격 성공률 (낮을수록 좋음)

새 결과 제보 CSV 직접 수정 (PR) GitHub 저장소

수치는 각 논문의 보고값이며, 논문마다 모델, AgentDojo 버전, 공격 설정이 달라 논문 간 비교는 참고용입니다.

내 결과 비교

한 줄에 하나씩 이름, 모델, Utility, Utility(공격 중), ASR. 숫자는 %, 없는 값은 비워 두거나 -. 입력값은 어디에도 저장되지 않으며 새로고침하면 사라집니다.

    Utility vs ASR

    왼쪽 위일수록 좋음 (공격은 막고 task는 잘 수행). x축은 0 근처를 펼쳐 보이기 위해 제곱근 스케일.

    전체 표
    열 제목을 누르면 정렬됩니다. 표의 행이나 차트의 점에 마우스를 올리면 서로 강조됩니다. 논문 이름의 링크는 원 논문, * 표시는 비고가 있는 행입니다.
