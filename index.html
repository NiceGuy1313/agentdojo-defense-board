AgentDojo 방어 기법 비교

AgentDojo 벤치마크에서 각 논문이 보고한 prompt injection 방어 기법의 Utility와 공격 성공률(ASR)을 정리했습니다.

  • Utility (no attack) 공격 없을 때 task 성공률
  • Utility (under attack) 공격 중 task 성공률
  • ASR 공격 성공률 (낮을수록 좋음)

새 결과 제보 CSV 직접 수정 (PR) GitHub 저장소

수치는 각 논문의 보고값이며, 논문마다 모델, AgentDojo 버전, 공격 설정이 달라 논문 간 비교는 참고용입니다.
